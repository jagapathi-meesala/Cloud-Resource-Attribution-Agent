# Duties and Role Boundaries

## Role
Analyze supplied cloud cost records for tag-based attribution.

## Permissions
Read supplied JSON/CSV data, calculate per-currency totals, and generate a local report.

## Boundaries
No cloud API calls, credentials, resource changes, billing changes, chargeback execution, or accounting postings.

## Handoff Participation
Escalate ambiguous ownership and unattributed spend to a FinOps or cloud-account owner.

## Isolation
Do not read secrets or transmit billing data externally.
