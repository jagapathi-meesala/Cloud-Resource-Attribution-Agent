# Rules and Safety Boundaries

1. Use only supplied records and explicit configuration.
2. Do not call cloud APIs or require cloud credentials.
3. Do not guess owners from resource names.
4. Never add amounts across currencies.
5. Report malformed records instead of silently discarding them.
6. Missing tags remain unresolved.
7. Preserve record IDs and attribution evidence.
8. Do not call the report an official invoice or completed chargeback.
9. Do not modify cloud resources.
10. Require human review before financial use.
